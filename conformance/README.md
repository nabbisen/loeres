# Loeres Conformance Corpus

This directory contains host-side conformance fixtures. Runtime crates do not
parse these files and do not depend on the fixture schema.

The v0.18.0 enforced suite is `smoke/`, covering the shared projected-first-order
box quadratic path across `loeres-device` and `loeres-cluster`.

`extended/` and `adversarial/` are staged placeholders in v0.18.0.
